Test sample


Keywords and text for the tester. The baked beans sample is only an example. Switching to Tester fills the form with this, and runs it with the config below.









  
  
  



Language packs live in langs/. Switching language reloads that pack into the editor and the tester sample. Language support is rudimentary — the packs are demos; proper localisation is left as an exercise for other quirky sluggers.



Settings


Press ? beside a setting to read what it does, and what changes when you edit it.








Lists


Each list works the same way: edit a row, move it, delete it, or add one. Order matters, because a seed picks by position.





Patterns


A pattern needs an id, trigger words, and at least one template. Quirky templates are optional.





  




Config JSON


This is the config the tester uses. Copy it into options.config, or into a JSON file you pass by path. The sample above is not part of it. Nothing is saved to disk.
